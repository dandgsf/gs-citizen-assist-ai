# Histórico de versões

## 0.1.1 — 12/11/2026

- Nome adotado: Citizen Assist AI, conforme o case oficial das instructions.
- Pasta e repositório definidos como `gs-citizen-assist-ai`.
- README, interface textual, prompts, metadados da base e documentação atualizados para o nome do case; identidade própria adiada.
- Histórico Git e tag inicial `v0.1.0` preservados.

## 0.1.0 — 12/11/2026

Primeiro versionamento do protótipo Citizen Assist AI, identificado como `gs-citizen-assist-ai` para a Global Solution FIAP 2026.2.

- Código Python existente, base com 23 orientações e 5 temas, conjuntos de teste e documentação incorporados ao Git.
- Enunciado fornecido incluído integralmente em `instructions.md`.
- README alinhado às instructions, com execução, autoria, resultados reproduzidos e pendências explícitas.
- Convenção de nomes e tópicos documentada em `docs/nomenclatura.md`.
- Avaliação reproduzida com Python 3.12.10: estratégia híbrida com 39/40 acertos no teste, 11/15 na validação e 12/12 verificações de robustez tratadas.

### Limitações conhecidas

- Erro V15: uma pergunta sobre cancelamento de academia recebe o registro de telecomunicações.
- Revisão humana das fontes, teste com usuário, experimento com prompts, PDF final e vídeo ainda pendentes.
- A versão inicial não representa a conclusão nem a submissão da atividade.
